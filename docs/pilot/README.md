## Before the first pilot

- [ ] Desktop verification from spike 0.1 done; 0.4 (write guard in Cowork) observed.
- [ ] Spike 0.5 run once (or the first pilot doubles as it).
- [ ] Screenshots added to `reference/connector-guides/` (3.3).
- [ ] Plugin packaged (`dev/package.sh`) or marketplace repo reachable by pilots (Q1 for the
      pilot: a private GitHub repo with pilots as collaborators is enough).
- [ ] Q5 answered: the 2–3 brands, at least one non-technical marketer in Claude Desktop, roles
      covering sponsorship, SEO and social.
