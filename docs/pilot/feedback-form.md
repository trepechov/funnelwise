# Pilot feedback (after 2 weeks)

Send as a form or ask in a 20-minute call. Scale questions 1–5.

1. How many times did you use Funnelwise in the last two weeks? (0 / 1–2 / 3–5 / more)
2. Which reports did you run? (media kit · SEO opportunities · content performance · connection
   check · something custom: ______)
3. Which report was most useful, and what did you do with it?
4. Did any report contain a wrong number or a claim you didn't trust? Which?
5. How easy was the setup? (1 very hard – 5 very easy) What was the hardest part?
6. Did anything stop working (a connection, a sign-in)? What?
7. Did the suggestions ("you could also run…") point you to something useful? (1–5)
8. What did you ask for that Funnelwise couldn't do?
9. Compared with how you made these reports before, how much time did it save per report?
10. Would you keep using it? (no / maybe / yes)
11. Would you pay for it? Setup only / monthly subscription / both / no. How much would feel fair?
12. Anything else?
