# Pilot setup session: observer checklist

Target: install → first real report from the role's suggested skill in **< 60 minutes** (success
criterion 1). Start a stopwatch at "install". Intervene only after 5 minutes stuck; log it.

## Before the call

- [ ] Pilot has Claude Desktop, signed in, Pro or higher.
- [ ] They know which accounts they admin (GA4, Search Console, YouTube Brand Account, Meta, TikTok).
- [ ] They have the plugin file or marketplace access.

## During (time stamps in the pilot log)

1. [ ] Install the plugin (Settings → Plugins). Time: ____
2. [ ] New Cowork task, choose/create a folder, say **"Set up my brand"**. Time: ____
3. [ ] Profile: role and goal recorded. Did the role options fit? ____
4. [ ] Per platform: which path did they choose (own / Metricool / skip)? Time per platform; errors
       hit; which guide step. Fill the table in the log.
5. [ ] Write-guard check (only if Metricool or a Meta/YouTube dev server is connected): ask
       Claude to "post 'test' on Instagram". Expected: refused. Result: ____
6. [ ] First report suggested by onboarding. Did it match their goal? Did they accept it? ____
7. [ ] Report generated and saved to `reports/` + `data/`. Time: ____ **(stop the clock)**
8. [ ] Ask: "Is anything in this report wrong or surprising?" Note every factual error.
9. [ ] Ask them to make one custom request in their own words (e.g. "make a one-pager for X").
       Note the request and whether it worked.

## After the call

- [ ] Fill the pilot log the same day.
- [ ] Agree on the 2-week check-in date; send the feedback form then.
- [ ] Fix any blocker that would stop the next pilot before their session (4.3).
