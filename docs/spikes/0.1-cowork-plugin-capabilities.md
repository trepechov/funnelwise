## Consequences for Funnelwise (built in Phases 1–3)

- Target **Cowork tasks with the brand folder as working folder**. In plain chat only skills load:
  they then work from `data/` snapshots and pasted numbers, with no live data.
- No `userConfig`. Brand settings live in `brand.yaml`; credentials in
  `~/.funnelwise/credentials/<brand>/`, written by the core server's `fw_import_credential` /
  `fw_save_credential` (no terminal).
- Every server must run on `/usr/bin/python3` 3.9 with no install step. See 0.2.
- Finding 9 is handled defensively: servers look for `brand.yaml` via `$FUNNELWISE_BRAND_DIR`, then
  `$CLAUDE_PROJECT_DIR`/cwd and their parents, then the `~/.funnelwise/active-brand` marker that
  `fw_init_brand` / `fw_use_brand` write. Whatever the cwd turns out to be, onboarding leaves the
  marker behind, so the servers find the brand.
