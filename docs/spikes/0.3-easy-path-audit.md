## Provisional answer to Q15 (to confirm after the live audit)

- **v1 officially supports Metricool** as the easy path for Instagram, Facebook, TikTok and
  YouTube *video-level* data. Caveat for sponsorship reports: the free plan shows only 30 days of
  history, so month-over-month diffs rely on Funnelwise's own `data/` snapshots (which is what they
  are for).
- **Google stays on our own server** (one service-account key for GA4 + GSC). Windsor's free tier
  covers only one of the two, and our GSC server adds `gsc_opportunities` and URL inspection.
  Windsor is documented as an alternative, not recommended.
- **Semrush optional** (Q7), only for brands whose plan includes MCP access.

## Live audit protocol (needs a Metricool account with a test brand)

For Metricool, in a Cowork task and in Claude Code:
1. List its tools; record exact names in `reference/sources.md` (replace the "verify" notes).
2. For each metric id in `reference/skill-catalog.yaml` → `media-kit` and `content-performance`,
   record: available? which tool and field? per-post or account-level? history limit?
3. YouTube: does it return watch time, average view duration, retention, demographics? (If not,
   those stay on the developer path; the YouTube guide already says so.)
4. Confirm the write guard blocks `post_schedule_post` in both hosts (the hook test covers the
   name; this checks the hook actually runs there, see 0.4).
5. Record the result as a Decision (Q15) in the plan.
