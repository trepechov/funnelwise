# Spike 0.5: setup friction test (protocol)

Question: how long does a non-developer take to connect GA4 + Search Console + YouTube with the
written guides, and where do they get stuck? Decides how hard to lean on easy paths and whether to
offer paid setup (Q4).

**Status: not run.** Needs one person who markets a brand, has admin access to its Google accounts,
and has never made a Google Cloud project.

## Setup

- Their own computer, Claude Desktop, Funnelwise installed (0.1 checklist), a Cowork task in an
  empty folder.
- Observer only watches (screen share is fine). Help only when they've been stuck for 5 minutes;
  write down every intervention.
- Guides: `reference/connector-guides/google.md` and `youtube.md`, opened by the onboarding skill.

## Measure

| Step | Start → end | Minutes | Stuck? (what, how long) | Helped? |
|---|---|---|---|---|
| Brand folder + profile | "Set up my brand" → profile saved | | | |
| Google Cloud project + APIs | guide step 1 → 2 done | | | |
| Service account + key import | step 3 → `fw_import_credential` ok | | | |
| GA4 access + property ID | step 6 → GA4 test call ✅ | | | |
| Search Console access + URL | step 7 → GSC test call ✅ | | | |
| YouTube | channel ID saved → public stats ✅ (Analytics optional) | | | |
| First report | suggestion accepted → report saved | | | |
| **Total** | | | | |

Also ask afterwards (1–5): how confident they'd be doing this alone, whether they would have given
up, whether they'd pay someone to do it, and how much.

## Decision rule

- Total ≤ 45 min, no step stuck > 10 min → keep the BYO Google path as the default.
- 45–90 min or one step stuck > 10 min → fix that guide step (screenshots, wording), re-test.
- > 90 min or they'd have given up → lead with easy paths everywhere possible and offer paid
  done-for-you setup (Q4) in onboarding.

Record the result in this file and as a Decision in the plan.
