# Spike 0.2: running our servers without a terminal

## Options considered (plan §5.3)

| | Option | Verdict |
|---|---|---|
| A | Desktop Extensions (`.mcpb`), one per server | Not needed now. Its main benefit (keychain via `user_config`) doesn't help, because Cowork doesn't prompt for config (0.1 #4), and Python servers would still need a bundled runtime. |
| B | Plugin `.mcp.json` launching via `uvx` | Fails on a marketer's Mac: `uv` isn't on the desktop app's PATH (0.1 #5). Kept only for the pinned third-party servers on the developer path. |
| C | Hybrid: plugin + `.mcpb` for some servers | Unnecessary once D works. |
| **D** | **Plugin `.mcp.json` launching `python3 server.py`, where every server is standard-library Python 3.9 and the few pure-Python libraries are vendored** | **Chosen** |

## What D means in code

- `servers/lib/mcp_stdio.py`: a ~200-line MCP stdio server (initialize, ping, tools/list,
  tools/call) replacing the `mcp` package's FastMCP. Input schemas come from type hints and
  docstrings.
- `servers/lib/google_auth.py`: Google service-account login without `google-auth`. It signs the
  JWT with RS256 using the system `openssl` binary (present on macOS and most Linux).
- `servers/_vendor/`: PyYAML 6.0.2, Jinja2 3.1.4 and MarkupSafe 2.1.5 in pure-Python form (no C
  extensions), licences in `servers/_vendor/licenses/`.
- `servers/ga4.py` replaces the `npx mcp-google-analytics` wrapper (no Node needed).
- Third-party servers (YouTube, Instagram, Facebook) still need `uv`. `servers/thirdparty.py`
  starts them when `uv` exists and `via: own`; otherwise it starts a one-tool stub that explains the
  easy path, so Desktop shows a helpful tool instead of a dead connector.

## Verified (2026-10-22, macOS 14, `/usr/bin/python3` 3.9.6, LibreSSL 3.3.6)

- All five own servers complete the MCP handshake and list tools on 3.9 (`dev/smoke.py`).
- Live, read-only, with a real brand's credentials: GA4 `runReport` (service account signed via
  openssl) ✅, Search Console site details and `gsc_opportunities` over 2,756 queries ✅, scope
  refusals for another site and another show ✅. Spotify returned 403 "Active premium subscription
  required for the owner of the app" (an account issue, now in the Spotify guide). TikTok was not
  signed in yet.
- Third-party servers start via the launcher when `uv` exists (YouTube 40 tools, Instagram 10,
  Facebook 40), after pinning `mcp<2` for Instagram and YouTube.
- Test suite runs on Python 3.9 (`uv run --python 3.9 …`).

## Open / risks

- **Windows**: no `/usr/bin/python3` and often no `openssl`. Not supported in v0.1; needs a
  decision (bundle a runtime via `.mcpb`, or a pure-Python RSA signer) before a Windows pilot.
- Credentials are files with mode 600 in `~/.funnelwise/credentials/`, not in the OS keychain.
  Acceptable for the pilot; revisit with `.mcpb` `user_config` if Cowork starts supporting it.
- If Apple removes `/usr/bin/python3` (it is a Command Line Tools shim on recent macOS, and the
  first call can trigger an install prompt), the plugin can't start. Mitigation: onboarding guide
  step "if macOS asks to install developer tools, accept".
