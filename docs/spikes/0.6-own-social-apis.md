# Spike 0.6: own YouTube, Instagram and Facebook servers

Question: can Funnelwise read YouTube, Instagram and Facebook itself, standard-library Python only,
and which current API names do the reports need? Status: **verified** 2026-10-22 with the first
customer's existing credentials (read-only calls).

## YouTube

- Data API `channels.list?id=` and Analytics `reports?ids=channel==<id>` work with an OAuth token of
  a Brand Account manager. `channels.list?mine=true` with the same token returns the signer's
  **personal** channel: confirms why Funnelwise never uses `mine`.
- The old third-party token carried write scopes (`youtube`, `youtube.upload`); ours asks for
  `youtube.readonly` + `yt-analytics.readonly` only.
- Traffic sources (`insightTrafficSourceType`) and watch time return rows for a 7-day window.
- Google apps in **Testing** mode end sign-ins after 7 days; the token response then carries
  `refresh_token_expires_in`, which the login tools use to warn at once.

## Instagram (Graph API v25.0)

- Profile, media list, media insights `views, reach, saved, shares, total_interactions` ✅.
  `impressions` is gone for reels ("does not support the impressions metric").
- Account insights `reach, views, accounts_engaged, total_interactions, profile_views,
  website_clicks` with `metric_type=total_value` ✅; `follower_count` per day ✅;
  `follower_demographics` by country/age ✅.

## Facebook

- Page fields `followers_count`, `fan_count` ✅. Insights need a **Page** token, derived from the
  system-user token with `GET /{page_id}?fields=access_token`.
- Working Page metrics: `page_media_view`, `page_total_media_view_unique`, `page_post_engagements`,
  `page_views_total`, `page_daily_follows_unique`, `page_video_views`, `page_follows` (running total).
  **Retired:** `page_impressions`, `page_impressions_unique`, `page_fans`.
- Post metrics: `post_media_view`, `post_total_media_view_unique`, `post_clicks`,
  `post_reactions_by_type_total`, `post_video_views`; `post_impressions_unique` retired. Without
  `period=lifetime` some come back twice (lifetime + daily rows): ask for lifetime.

## Credentials

- The customer's Meta tokens are **System User** tokens (`expires_at: 0`): no 60-day renewal. The
  guide uses that path; one token covers both platforms.

## Result

The three servers (`servers/youtube.py`, `instagram.py`, `facebook.py`) ran every tool live:
14 read calls, all ✅. Unverified: the Meta System User setup steps with a brand-new business
(screenshots for T6), and the Google "Publish app" path end to end with a fresh project.
